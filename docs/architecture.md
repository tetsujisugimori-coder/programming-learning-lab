# 教材基盤と拡張

2026-11-05 JST / Issue #1。既存mainはREADMEのみ。既存の実装フレームワーク・lint・型検査・公開手順はなかったため、Vite + TypeScript + Web標準の静的サイトを採用。実行時の外部ライブラリ・外部フォント・AI通信はない。

## データと表示

- `src/curriculum.ts`：言語登録、13章の到達目標とready、8節の説明・例・予想・変更・確認・1問のチェック・誤答理由・段階ヒント・解答例。chapter/lesson/quiz/example/prediction/practiceに安定IDを持つ。
- `src/components.ts`：説明／課題、コードカード、native details、separator。文字列はHTML escapeし、自由記述をHTMLとして再描画しない。
- `src/main.ts`：節と一覧の切替、URL hash、読了／正解／PC自己申告を別々に管理、Clipboard APIのPromise結果。教材DOMは初回に構築し、その後hiddenで切り替えるためtextarea・radio・detailsを保持する。ブラウザーの戻る／進むもhashに同期。
- `src/style.css`：PCの2列、900px以下の縦配置、700px以下の節ナビゲーション、rem文字、focus-visible、reduced-motion。

新しい言語は `languages` に安定IDを登録し、同様のChapter/Lessonデータを言語別モジュールへ分割して接続できる。今回の他言語表示は追加予定を知らせる文字ラベルのみ。本文や空リンクを用意していない。第2章以降は一覧カードで到達目標と「準備中」を示し、未完成ページへの遷移・完了操作を作らない。

## 学習状態の意味

|状態|記録する操作|意味|
|---|---|---|
|読了|学習者がチェック|読んだという自己記録|
|理解チェック正解|回答確認ボタンで選択を判定|その1問の正解。選び直すと未判定へ戻す|
|PC実行の自己申告|学習者がチェック|PCで確かめたという申告。サイトでは成功を観測できない|
|自由記述|textareaの入力|メモ。採点・単語一致判定・サーバー送信なし|

上記を合算して「章完了」と自動判定しない。表示例は教材として用意した例。実行ボタンは設けない。サイトが利用者のPC上の環境を検査・変更することもない。

ヒントは1を開くと2の見出し、2を開くと解答例の見出しが現れる。閉じても解放済み段階は保ち、解答本文は操作するまで閉じている。移動のために回答・実習の記録を強制しないため、iPhoneでは予想と理解チェックに取り組み、後からPCで実習できる。

幅調整は35〜65%、左右矢印で5%、Home/End、ダブルクリック／幅初期化に対応。Pointer Captureの取消・画面非表示・resizeでドラッグを終える。狭幅はseparatorを非表示にし自然な縦配置。コードpreだけが横スクロール可能。

## 開発・公開

Node.js 24、npm lockfileを使用。`--configLoader native` でViteの設定をNodeから読み、制限されたWindows環境でesbuildが親ディレクトリ探索に失敗する経路を避ける。dev/previewは127.0.0.1だけにbind。ブラウザー検査は`tools/browser-test.mjs`が空きポートの静的サーバーを所有し、Playwrightの終了時に閉じる。Windowsのプロセスツリー終了待ちに依存せず、既存サーバーも再利用しない。buildはdistのみ、証拠・参照コピー・node_modulesは配信しない。相対アセット指定で静的サブパスに配置可能。

新規依存導入時のaudit警告に対応し、Vite7.3.7、typescript-eslint8.72.1、esbuild0.28.2へ更新。minimatchは監査指摘範囲を避け11.0.1へoverrideした。lint・型検査・build・ブラウザー検査で使用経路を検証し、lockを固定。監査0件は確認時点の結果であり将来の無欠陥保証ではない。
